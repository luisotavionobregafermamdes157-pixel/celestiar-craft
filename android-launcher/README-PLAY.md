# Brasilia Craft — jogar de verdade

Esta pasta contém o launcher Android/HTML do Brasilia Craft.

O HTML pode consultar o manifesto oficial de versões do Minecraft, mas um navegador não consegue iniciar diretamente um cliente Minecraft Java completo.

Para uma versão jogável no Android, o projeto precisa integrar um runtime Java compatível com Android, downloads dos arquivos oficiais, autenticação Microsoft/Minecraft e um processo de lançamento compatível com cada versão. O usuário precisa ter uma licença/acesso legítimo ao Minecraft Java Edition.

O projeto não inclui código proprietário da Mojang nem bypass de autenticação.
